# Proyecto Python Final

>`¿Que es una Pip?`
>>Son las reglas de "Pip Installs packages", es el gestor oficial de paquetes de Python

>`¿Que significa "Gestor de Paquetes"?`
>>Es un programa que permite la instalacion de librerias, desintalarlas, ver cuales estan instaladas, bucar paquetes, guardar dependencias e instalar desde un archivo

>`¿Por que es tan importante?`

>>Sin pip, tendrias que buscar librerias en internet, descargarlas manualmente, descomprimirlas, y ejecutar un scrip de instalacion; pip automatiza todo eso en un solo comando

>`¿Porque las actualizamos?`
>>Las actualizamos con razon de seguiridad, las versiones nuevas corrigen vulnerabilidades que podrian explotar atacantes, Compatibilidad paquetes nuevos requieren versiones recientes de pip para instalarse correctamentel; Rendimiento, Nueva Funciones, Evitar advertencias entre otras cosas. 
>>Como dato importante las vesiones que vienen con Python suelen ser mas antiguas. Al actualizarlo, te aseguras de tener lo ultimo sin tener que actualizar todo Python
